what is zero trust security spring
In the context of the Spring ecosystem (like Spring Boot and Spring Cloud), Zero Trust Security is an architectural strategy based on the principle of "never trust, always verify". 

SpringSource
 +1
Instead of relying on a secure network perimeter (the traditional "castle-and-moat" approach where everything inside the network is implicitly trusted), a Zero Trust architecture assumes that threats can exist inside the network. In Java and Spring microservices, this means every user, application, device, and service-to-service communication must be explicitly authenticated, authorized, and encrypted.

why do we need cujrsor ide, can we not use vs code for mcp server coding
You absolutely can use VS Code for MCP (Model Context Protocol) server coding. In fact, many developers prefer it because the official Anthropic MCP TypeScript and Python SDKs are built to be standard-agnostic, running smoothly in any standard terminal, runtime environment, or editor.
However, developers choose Cursor IDE over VS Code for MCP development for a few specific reasons:
1. Ready-to-Use Native MCP Client Support
The biggest differentiator is that Cursor has a built-in MCP Client built into its settings menu.
In Cursor: You can plug your custom MCP server directly into Cursor's Features > MCP configuration pane. Cursor will immediately launch and communicate with your local server, allowing its native AI agent (Composer / Chat) to call your server's tools in real-time as you code it. This creates an immediate feedback loop for testing.
In VS Code: VS Code itself does not act as an MCP host natively. To test an MCP server inside VS Code, you have to install a third-party extension (like Roo Code, Cline, or the official Claude Dev extension) that acts as the client host.
2. Multi-File AI Agents (Composer)
When writing an MCP server, you are often bridging two worlds: the MCP schema definitions and the actual API/service you are connecting to.
Cursor's Composer (Ctrl+I / Cmd+I) can edit and reason across multiple files simultaneously. It can generate the tool definition schema in your server file, update your configuration JSON, and write the backend logic synchronously.
3. Deeper Context Integration
Cursor treats your entire codebase, documentation, and terminal outputs as a unified context graph. When building an MCP server, you often need to reference specific external SDK documentation or API endpoints. Cursor allows you to scrape and index those docs directly into the LLM context using the @Docs feature, making the generation of MCP tool schemas highly accurate.
Comparison: VS Code vs. Cursor for MCP Development
Feature	VS Code	Cursor IDE
MCP Server Coding	Yes, fully supported via terminal/runtimes.	Yes, fully supported.
Testing your Server	Requires extensions (e.g., Cline, Roo Code).	Built directly into the IDE settings panel.
Multi-file generation	Limited to basic copilot code completion.	Advanced multi-file AI edits (Composer).
Underlying Engine	The baseline platform.	Fork of VS Code (supports all your VS Code extensions).
The Bottom Line
If you are already comfortable with VS Code, you can easily use it alongside an extension like Cline to build and test MCP servers. However, because Cursor is essentially a fork of VS Code, it lets you keep all your favorite VS Code themes, shortcuts, and extensions while giving you a tighter, native loop for testing your new MCP tools.

Step 4: Create the Dubai Scraper (scraper.py)
This script uses Playwright to open a headless browser, navigate to a localized Dubai job board (e.g., Indeed UAE), search for your keywords, and extract the raw HTML job cards into a local file.
python
import asyncio
from playwright.async_api import async_playwright
from bs4 import BeautifulSoup
import json
import os

async def scrape_dubai_jobs(keyword, location="Dubai"):
    print(f"🕵️‍♂️ Searching for '{keyword}' jobs in {location}...")
    
    async with async_playwright() as p:
        # Launch browser (headed=False means it runs completely in the background)
        browser = await p.chromium.launch(headless=True)
        page = await browser.new_page()
        
        # Format URL for Indeed UAE
        url = f"https://indeed.com{keyword.replace(' ', '+')}&l={location}"
        await page.goto(url, wait_until="networkidle")
        
        # Allow extra time for dynamic elements to load
        await page.wait_for_timeout(3000)
        
        content = await page.content()
        soup = BeautifulSoup(content, 'html.parser')
        
        job_listings = []
        
        # Find job cards (Indeed's CSS classes change, but 'resultContent' is standard)
        cards = soup.find_all('div', class_='resultContent')
        
        for card in cards:
            title_element = card.find('h2', class_='jobTitle')
            company_element = card.find('div', class_='companyName') or card.find('span', data_testid='company-name')
            location_element = card.find('div', class_='companyLocation') or card.find('div', data_testid='text-location')
            
            title = title_element.text.strip() if title_element else "N/A"
            company = company_element.text.strip() if company_element else "N/A"
            loc = location_element.text.strip() if location_element else "N/A"
            
            job_listings.append({
                "title": title,
                "company": company,
                "location": loc,
                "raw_text": card.text.strip()
            })
            
        # Save raw data
        os.makedirs('data/raw', exist_ok=True)
        with open('data/raw/jobs.json', 'w', encoding='utf-8') as f:
            json.dump(job_listings, f, indent=4, ensure_ascii=False)
            
        print(f"✅ Successfully scraped {len(job_listings)} jobs into data/raw/jobs.json")
        await browser.close()

if __name__ == "__main__":
    asyncio.run(scrape_dubai_jobs("Software Engineer"))

Step 5: Build the Agentic Analyzer (analyzer.py)
This script acts as the "Agent Core". It loads your resume, your target criteria, and the raw jobs file. It then sends them to Claude to score and filter out bad matches.
python
import json
import os
from anthropic import Anthropic
from dotenv import load_load_env # type: ignore

load_env()

def analyze_and_rank():
    # Load profile data
    with open('data/context/resume.txt', 'r') as f:
        resume = f.read()
    with open('data/context/preferences.txt', 'r') as f:
        preferences = f.read()
    with open('data/raw/jobs.json', 'r') as f:
        jobs = json.load(f)
        
    client = Anthropic(api_key=os.getenv("ANTHROPIC_API_KEY"))
    
    print("🧠 Claude is analyzing and ranking matches based on UAE standards...")
    
    # Prompting Claude to act as a career agent matching your specific profile
    prompt = f"""
    You are an expert AI Career Agent specializing in the Dubai and UAE tech sectors. 
    Analyze the following list of job postings against the user's Resume and Preferences.
    
    ### USER RESUME ###
    {resume}
    
    ### USER PREFERENCES ###
    {preferences}
    
    ### SCRAPED JOBS ###
    {json.dumps(jobs, indent=2)}
    
    ### INSTRUCTIONS ###
    1. Score each job from 0 to 100 based on fit.
    2. Sort them from highest score to lowest score.
    3. For any job with a score > 75, provide a 2-sentence rationale on why it fits, and list any missing skills or requirements the user needs to highlight or address.
    4. Provide the output strictly in a readable Markdown format. Do not use generic filler. Include visa or location callouts specific to Dubai if applicable.
    """
    
    message = client.messages.create(
        model="claude-3-5-sonnet-latest",
        max_tokens=4000,
        temperature=0.2,
        messages=[{"role": "user", "content": prompt}]
    )
    
    # Output report
    output_path = 'data/processed/ranked_dubai_jobs.md'
    os.makedirs('data/processed', exist_ok=True)
    with open(output_path, 'w', encoding='utf-8') as f:
        f.write(message.content[0].text)
        
    print(f"📊 Assessment complete! Open '{output_path}' to view your target list.")

if __name__ == "__main__":
    analyze_and_rank()
